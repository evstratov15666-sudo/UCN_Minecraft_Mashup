# Ultimate Minecraft Night

A mashup of **Ultimate Custom Night** and **Minecraft: Java Edition** created for Melty.gg.

## Concept

Defend your office against waves of animatronics AND Minecraft mobs across 7 nights. Collect Minecraft blocks, craft tools, place structures, and use dynamite to destroy threats while protecting critical infrastructure.

## Features

- **Hybrid Enemies**: All original UCN animatronics + Minecraft creatures (Creepers, Endermen, Withers, Zombies, Skeletons)
- **Inventory System**: Collect and manage Minecraft blocks in real-time
- **Crafting Mechanics**: Craft tools and defensive structures
- **Dynamite Destruction**: Use explosives to destroy blocks and eliminate threats
- **Adjustable AI**: Set difficulty (0-20) for each enemy type
- **7 Nights Progression**: Increasing difficulty with each night
- **Single Player & Multiplayer**: Solo or co-op up to 4 players
- **Protected Locations**: Office desk, corridors, and vents cannot be destroyed

## Requirements

- Windows 10/11
- Ultimate Custom Night (installed)
- Minecraft: Java Edition (installed)
- Melty.gg launcher

## Installation

1. Launch Melty.gg
2. Search for "Ultimate Minecraft Night"
3. Click "Install"
4. Follow one-click setup
5. Select difficulty and start your first night

## Gameplay

### First Night
1. Sit at your office desk
2. Select animatronics and their difficulty (0-20)
3. Select Minecraft mobs and their difficulty
4. Night begins
5. Use your inventory to collect blocks
6. Craft items using Minecraft recipes
7. Place blocks to build defenses
8. Use dynamite to destroy threats
9. Survive until 6 AM

### Game Controls
- **Mouse + Keyboard**: Standard UCN + Minecraft controls
- **I Key**: Open Inventory
- **E Key**: Open Crafting Menu
- **Left Click**: Place block / Attack
- **Right Click**: Destroy block / Interact
- **Number Keys**: Quick select from inventory
