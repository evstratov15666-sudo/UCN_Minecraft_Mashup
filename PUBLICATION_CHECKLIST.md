## 📞 Support & Maintenance

### Common Issues & Fixes

**Issue: "Games not found"**
- User needs to install both UCN and Minecraft first
- Point to INSTALLATION.md

**Issue: "UI fails to load"**
- Clear browser cache
- Reinstall mashup
- Check melty.json validity

**Issue: "Multiplayer not connecting"**
- Must be on same network
- Check firewall settings
- Verify both players have latest version

### Update Process (Future)

For v0.2.0+:
1. Update version in package.json
2. Create new archive
