## 🎮 Gameplay

**Objective:** Survive 7 nights against combined threats

**Mechanics:**
- 22 Animatronics + 5 Minecraft Mobs
- Block inventory (14 block types)
- 9 Crafting recipes
- Dynamite explosives
- Difficulty 0-20 per enemy
- Single & Multiplayer modes

**Resources:**
- Starting: Stone, dirt, planks, sticks
- Craft: Tools, doors, chests, TNT
- Progress: More resources each night

## 🚀 Getting Started

### Installation (One-Click via Melty)
1. Install Ultimate Custom Night
2. Install Minecraft: Java Edition
3. Open Melty.gg
4. Search "Ultimate Minecraft Night"
5. Click Install
6. Play!

### First Game
1. Setup screen appears
2. Select night (1-7)
3. Choose difficulty (0-20 per enemy)
4. Pick game mode
5. Click "Start Night"
6. Survive until 6 AM!

## 🛠️ Development

### Tech Stack
- **Runtime:** Node.js 14+
- **Frontend:** HTML5 + CSS3 + Vanilla JavaScript
- **Build:** Bash/Batch scripts
- **Package:** ZIP archive

### Architecture
- Modular systems (each self-contained)
- Central game controller (orchestrates)
- Separation of concerns
- No external dependencies
